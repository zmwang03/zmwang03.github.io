# ZM Wang Blog

This repository contains the source for `zmwang03.github.io`, a personal blog built with [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) and customized from the structure of [tremo1/tremo1.github.io](https://github.com/tremo1/tremo1.github.io).

Planned live URL: [zmwang03.github.io](https://zmwang03.github.io)

## Local Development

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve`.
4. Open `http://127.0.0.1:4000`.
